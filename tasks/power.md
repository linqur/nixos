# Питание ноутбука: ПО ASUS, режим GPU, экран, батарея

Статус: решения приняты. Сделан только порог заряда (`nixos/battery.nix`), остальное — без изменений в конфиге.
Проверено на ROG Strix G18 (G815JMR), ядро 7.2, niri 26.04.

## ПО ASUS (asusd, supergfxd, rog-control-center)
Решение: **не ставить.** Ядро (`asus_wmi`, `asus_armoury`) уже даёт через `/sys` всё нужное:
- профиль платформы: `/sys/firmware/acpi/platform_profile` (quiet / balanced / performance);
- лимиты CPU и GPU: `/sys/class/firmware-attributes/asus-armoury/attributes/` (`ppt_pl1_spl`, `ppt_pl2_sppt`, `nv_tgp`, `nv_dynamic_boost`, `nv_temp_target`), значения читаются только от root;
- MUX и отключение dGPU: `gpu_mux_mode`, `dgpu_disable`;
- кривые вентиляторов: hwmon `asus_custom_fan_curve`;
- порог заряда: `BAT0/charge_control_end_threshold`;
- яркость подсветки клавиатуры: `leds/asus::kbd_backlight`.

Против asusd:
- демон от root работает постоянно, хотя настройки нужны один раз при загрузке;
- API через D-Bus для изменения лимитов питания и вентиляторов — лишняя поверхность атаки;
- пишет свои настройки в `/etc/asusd/*.ron` — с overlay `/etc` это ложится в верхний слой (см. Readme);
- при смене профиля перезаписывает EPP — конфликт с планом из [cpu.md](cpu.md).

Против supergfxd: RTD3 уже работает, режим Integrated почти ничего не добавляет; переключение MUX всё равно требует перезагрузки.

Вернуться к вопросу, если понадобятся: эффекты RGB-подсветки (без asusd есть только яркость) — asusd; проброс GPU в VM — supergfxd.

## Режим GPU
Решение: **гибрид** (Intel рисует экран, NVIDIA — через `nvidia-offload`).
- Проверено: без нагрузки dGPU в `D3cold` (`/sys/bus/pci/devices/0000:01:00.0/power/runtime_status` = `suspended`).
- MUX (только NVIDIA): +5–15% FPS и меньше задержка в играх, но в простое примерно на 6–12 Вт больше (порядок величины, не замер). Сломанный драйвер из unstable даёт чёрный экран, в гибриде экран остаётся на Intel. Допустимо только как исключение на время игры, с перезагрузкой.
- Integrated (`dgpu_disable`): экономия против `D3cold` — доли ватта; не работают порты на NVIDIA.
- Частые включения и выключения dGPU (RTD3) не изнашивают её: износ зависит от напряжения и температуры во времени, а размах температуры при переходе сон / простой — несколько градусов.
- Порты: к NVIDIA подключены `HDMI-A-1`, `DP-1`, `DP-2`, `eDP-1` (путь MUX); к Intel — `eDP-2` (встроенный экран). Внешний монитор через HDMI, скорее всего, держит dGPU включённой.
- gamescope: вложенный в niri работает в гибриде (`--prefer-vk-device`). Отдельная сессия gamescope с TTY на NVIDIA требует MUX: встроенный экран подключён к Intel.

## Частота экрана
Решение: **240 Гц**, как сейчас.
- Панель BOE NE180QDM-NZC, EDID: фиксированные режимы только 60 и 240 Гц (2560×1600), Adaptive Sync 48–240 Гц (Fixed Average V-Total).
- **120 Гц не работает на Intel.** Modeline с таймингами 240 Гц и удвоенным Vtotal (`1175.04 2560 2608 2640 2720 1600 3406 3412 3600 -hsync -vsync`) драйвер отклоняет: в журнале niri `DrmError(TestFailed)`. Вероятно, драйвер Intel на eDP принимает только частоты фиксированных режимов, поэтому `custom=true` тоже не поможет.
- 60 Гц — официальный и самый экономный, отклонён: недостаточно плавно.
- 120 через MUX ради экономии бессмысленно: MUX тратит больше, чем экономит 120 Гц.
- 120 через подмену EDID отклонено: глубокое вмешательство ради 1–2 Вт.
- Цена 240 Гц: растёт только во время движения на экране, статичный экран держит PSR.

## Игры
- Ограничение FPS 120 (в настройках игры): видеокарта не рисует лишнего, 120 делит 240 ровно — без рывков даже без VRR.
- VRR (`variable-refresh-rate on-demand=true` + правила окон) — позже, вместе с настройкой игр ([arch-migration.md](arch-migration.md)).

## Батарея
Решение: **порог 75%**, `nixos/battery.nix` (правило udev при каждой загрузке: ASUS сбрасывает порог).
- 4 ячейки, литий-ион (высоковольтный, ~4,3 В на ячейку при 100%). Здоровье на 2026-10-22: 76,6 из 90 Вт·ч (~85%), `cycle_count` прошивка не сообщает.
- Износ ускоряют высокий заряд (напряжение) и тепло; от сети на 100% — худший случай.
- MyASUS предлагает 60 / 80 / 100. Выбрано 75 — между ними.
