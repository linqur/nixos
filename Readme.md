# NixOS-конфигурация

Воспроизводимая домашняя система: одна конфигурация даёт одинаковый результат на любом устройстве.

## Принципы

1. **Только нужное.** Включено только то, чем я реально пользуюсь. Остальное выключено или работает в минимальном режиме.
2. **Не используется — не потребляет.** Никаких автозагрузок, предзапусков и фоновых проверок по умолчанию. Медленный холодный старт допустим.
3. **Исключения — осознанные.** Автозапуск включается вручную для конкретной программы, если я так решил.

## Приоритеты оптимизации

Если подходит несколько решений, выбираю по порядку:

1. **CPU / GPU — температура и ресурс.** Меньше нагрева и деградации, выше отзывчивость.
2. **Сеть — сначала стабильность, потом трафик.** Системные настройки стека (например, TCP BBR), экономия трафика — в настройках конкретных приложений.
3. **Диск (NVMe) — износ.** Меньше лишних записей.
4. **Память — объём потребления.**

Общее ограничение: оптимизация сети, диска или памяти не должна заметно нагревать компоненты.
