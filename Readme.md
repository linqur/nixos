# NixOS-конфигурация

Воспроизводимая домашняя система: одна конфигурация даёт одинаковый результат на любом устройстве.

## Принципы

1. **Только нужное.** Включено только то, чем я реально пользуюсь. Остальное выключено или работает в минимальном режиме.
2. **Не используется — не потребляет.** Никаких автозагрузок, предзапусков и фоновых проверок по умолчанию. Медленный холодный старт допустим.
3. **Исключения — осознанные.** Автозапуск включается вручную для конкретной программы, если я так решил.

## Приоритеты оптимизации

Если подходит несколько решений, выбираю по порядку:

1. **CPU / GPU — температура и ресурс.** Меньше нагрева и деградации, выше отзывчивость.
2. **Сеть — сначала стабильность, потом трафик.** Системные настройки стека (например, TCP BBR), экономия трафика — в настройках конкретных приложений.
3. **Диск (NVMe) — износ.** Меньше лишних записей.
4. **Память — объём потребления.**

Общее ограничение: оптимизация сети, диска или памяти не должна заметно нагревать компоненты.

## Что помнить при правке конфига

Работа, которую NixOS по умолчанию делает на каждой загрузке, перенесена на сборку. Цена — несколько правил.

### Home Manager активируется только при смене поколения (`nixos/home-manager.nix`)

- Файлы в `~`, которыми управляет Home Manager, при загрузке не восстанавливаются. Удалил или правил руками — вернёт только rebuild с изменениями в Home Manager.
- Приложение может подменить симлинк своим файлом (VS Code — `settings.json`, GTK-программы — свои настройки). Такой файл живёт до следующего изменения Home Manager.
- Принудительная активация: `rm ~/.local/state/home-manager/gcroots/current-home && sudo systemctl restart home-manager-linqur`.

### nixos-init, overlay `/etc`, userborn (`nixos/init.nix`, экспериментально)

- **`system.activationScripts` молча не выполняются.** При добавлении модуля или flake-входа (sops-nix, agenix и т.п.) проверить, не работает ли он через activationScripts: `grep -o 'snippet [^:]*' result/activate`. Сейчас там только то, что nixos-init/userborn/overlay покрывают сами.
- **Не править `/etc` руками.** Правка ложится в верхний слой overlay и перекрывает версию из всех следующих сборок. Всё — через `environment.etc`.
- Первое включение (и откат на поколение без него) — через `nixos-rebuild boot` + перезагрузку, не `switch`. При проблеме — предыдущее поколение в меню systemd-boot.
