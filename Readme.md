# Мой NixOS

### Основная цель 
создать воиспроизводимую домашнюю систему, которую можно устанавливаать на разных устройствах и она будет максимально одинаковой. 

### Главные предпочтения 
минимум потребления ресурсов, максимальная производительность. То есть нужно определить что мне вообще нужно по функционалу и слделать так чтобы этот функционал полностью работал как и ожидается, потребляя при этом минимум ресурсов. Весь остальной функионал отключаем или переводим/конфигурируем в режим минимального потребления ресурсов. Если программа не используется здесь и сейчас значит она не должна потреблять вообще никаких ресрсов системы, даже если это увеличит время ее запуска когда она понадобится, то есть никаких предзапусков, предпроврок, предустановок, автозагрузок поумолчанию, до тез пор пока я намеренно не решу иного для конкретной программы

### Приоритеты
От большего к меньшему, что нужно оптимизировать в первую очередь и что в последнюю, если есть несколько решений, то больше склоняться к выбору согласно этому приоритету.
CPU+GPU -> netword -> disk -> memory.
